How it works Model GitHub

Describe a product in your own words, or show a photo. The model finds the closest matches among 121,549 real Amazon listings. Everything runs inside your browser: no server, nothing you type or upload leaves your device.

    How it works

    1. Your words or photo become a vector.A CLIP model turns text and images into 512 numbers that live in the same space, so "red sneaker" and a photo of one land close together.
    2. The model was fine-tuned on Amazon listings.Trained with a contrastive loss on 109,395 product photo–title pairs from the Amazon Berkeley Objects dataset, so it learned how products are actually described.
    3. FAISS finds the nearest products.Every catalog photo is pre-embedded into a compressed IVF-PQ index. A query is compared against all 121,549 products in milliseconds.
    4. It all runs in your browser.The CLIP encoders are exported to ONNX and quantized to INT8, then run with ONNX Runtime Web (WebAssembly). The IVF-PQ index ships as ~6 MB of plain arrays and is scanned exhaustively in JavaScript. The same model is also served as a Dockerised FastAPI API on AWS EC2.
